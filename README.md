# Revit2025-IntersectionInsertion-Plugin
Plugin para o Revit 2025 que busca intersecção entre tubos e piso (laje) para inserir modelo de furo.

Para gerar o instalador, basta compilar o projeto Thorus-RevitIntersectionPlugin, e depois o Thorus-RevitIntersectionPluginInstaller.
O arquivo de instalação já se encontra na pasta ThorusRevitIntersectionPluginInstaller\Release do projeto.

Ao fazer as devidas Builds, ele irá atualizar esses arquivos. Atualmente ele está direcionado para a versão 2025 do Revit, sendo instalado apenas para o usuário local (users/[nome-do-usuario]/AppData/Roaming/Autodesk/Revit/Addins/2025).
